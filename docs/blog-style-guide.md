## 1. 글의 뼈대

1. **도입부 — "왜?"로 연다.** 배경/문제 제시, 흔한 오해 깨기, 또는 질문 던지기로 동기부여한다. "주입식 암기 말고 원리를 이해하자" 같은 태도.
2. **본문 — 점진적 복잡도.** 쉬운 것 → 어려운 것 순으로 쌓는다. 각 개념은 **설명 → 그림 → 예시** 흐름으로 반복한다.
3. **마무리 — 한 문장 요약.** "글쓴이가 하고 싶은 말은…" 식으로 핵심을 재강조하고, 관련/다음 글을 링크한다.
4. **참고자료 섹션 — 필수.** 출처·공식 문서 링크를 나열한다(아래 9절).

## 2. 이미지·다이어그램 (최대 시그니처 — 가장 중요)

- **개념 하나 설명하면 곧바로 그림 한 장.** inpa 글의 정체성. 이미지 밀도를 높게 유지한다. 심화 글은 거의 매 섹션에 그림.
- **텍스트보다 먼저 개념을 시각화**하려는 의도로 배치한다(설명 직후 또는 직전).
- 종류: **다이어그램은 SVG로 제작**(흐름도·비교표·구조도), 툴/화면 소개는 스크린샷·GIF.
- 저장·명명·언어쌍(`.ko.`/`.en.`) 규칙은 **[`CLAUDE.md`](../CLAUDE.md)의 이미지 규칙**을 따른다(훅이 강제).
- **alt 텍스트**는 그림 내용을 요약해 접근성·검색성을 확보한다.

## 3. 헤딩·이모지

- **메인 제목과 주요 섹션 헤딩에 관련 이모지**를 붙여 스캔성을 높인다(🌐 📚 ⚡ ☁️ 🔁 🤔 💡 …).
- 심화 글은 **질문형 제목**(🤔 "~는 항상 좋을까?")이나 **번호 섹션**(1., 2. …)으로 논리 구조를 드러내도 좋다.
- 헤딩은 계층을 명확히(`##` → `###`). 한 화면에 소제목이 자주 보이게 해 "훑어 읽기"가 되게 한다.
- **목차는 자동 생성된다** — 본문에 목차를 손으로 쓰지 말 것. `##`/`###` 헤딩이 제목 아래 계층형 목차와 우측 네비게이션으로 자동 변환된다(헤딩 2개 미만이면 생략). 따라서 **헤딩 문구 자체가 목차 항목**이 되니, 길고 서술적인 제목보다 스캔되는 제목이 좋다.

### 커스텀 이미지 이모지 (`:이름:`)

유니코드 이모지로 부족할 때(로고·서비스 아이콘·캐릭터 등) 이미지를 이모지처럼 쓸 수 있다.

1. 이미지를 **`src/assets/emoji/<이름>.<확장자>`** 에 둔다. 크기는 신경 쓰지 않아도 된다 — 다운받은 원본을 그대로 넣으면 빌드가 알아서 줄이고 webp로 바꾼다.
2. 본문·헤딩·**글 제목(frontmatter `title`)·설명** 어디서든 `:이름:` 으로 부른다.

```markdown
---
title: ':astro: Astro로 블로그 만들기'
description: ':astro: 정적 사이트 생성기로 한/영 블로그를 만든 기록'
---

## :astro: 왜 Astro인가

Astro는 :zero-js: 기본값으로 JS를 보내지 않는다.
```

> ⚠️ **frontmatter에서는 값 전체를 반드시 따옴표로 감쌀 것.** `title`·`description`은 YAML이라, 값이 `:` 로 시작하면 YAML이 그걸 매핑 구분자로 오해해 `bad indentation of a mapping entry` 로 빌드가 죽는다. 본문에서는 따옴표가 필요 없다.
>
> ```yaml
> description: :claude: 훅을 설정하는 법   # ✗ YAML 파싱 에러
> description: ":claude: 훅을 설정하는 법"  # ✓
> ```

- **이름 규칙**: 영소문자로 시작, 2자 이상, `a-z 0-9 _ -`. 파일명이 곧 이름이다.
- **확장자**: `.png .jpg .jpeg .webp .svg`. **`.gif`는 막아 두었다** — 리사이즈하면 애니메이션이 첫 프레임만 남아 조용히 깨지기 때문.
- **크기는 항상 글자 높이(1em)** 에 맞춰진다. 제목에 쓰면 제목 크기로, 본문에 쓰면 본문 크기로 자동으로 따라간다.
- **목차·글 목록 카드에도 그대로 나온다.** 브라우저 탭 제목처럼 이미지를 넣을 수 없는 자리에서는 토큰이 자동으로 제거된다.
- **오타는 빌드가 막는다.** 등록되지 않은 이름을 쓰면 빌드가 실패하며 비슷한 이름을 알려준다.
- **콜론 표기를 그대로 보여주고 싶으면** 인라인 코드로 감싼다: `` `:sample:` ``. 코드블록 안도 건드리지 않는다. `10:30:00`, `3:2:1` 같은 자연스러운 콜론 표현도 안전하다.
- dev 서버를 켠 채로 새 이모지 파일을 추가했다면 **서버를 다시 시작**해야 인식된다.

## 4. 강조·콜아웃 (마크다운 네이티브로 구현)

이 블로그는 Tistory의 컬러 형광펜/박스 위젯이 **없다.** 아래로 대체한다.

- **`**굵게**`** — 핵심 용어·키워드. 남발하지 말고 진짜 중요한 곳만.
- **`> 💡 …` 콜아웃** — 팁, 주의, "이럴 때 씁니다" 같은 실전 포인트. 이모지로 성격 표시(💡 팁 · ⚠️ 주의 · ✅ 권장).
- **`> …` 인용구** — 용어 정의, 보충 설명, 예시를 본문과 분리해 담는다(inpa가 정의 블록에 쓰는 패턴).
- 강조 문장은 문단 안에서 **굵게** 처리해 "결론 한 방"을 만든다.

## 5. 표

- **비교·대조**(장단점, A vs B, 옵션별 차이), **매핑**(트리거 → 의미, 키 → 동작)에 쓴다.
- 스캔이 목적이므로 셀 내용은 짧게. 긴 설명은 본문으로 뺀다.

## 6. 코드블록

- **개념을 구체 코드로 보여줄 때** 쓴다. How-to·심화 글에서 적극, 순수 개념 글에서는 최소화(레퍼런스 개념글엔 코드가 거의 없음).
- **언어 태그를 명시**(```json, ```bash 등). 예시는 짧고 핵심만.
- 명령/키/파일명은 인라인 코드(`` `...` ``)로 표기.

## 7. 리스트

- **순서 있는 절차**(설정 단계, 동작 흐름) → **번호 리스트** `1. 2. 3.`
- **병렬 항목**(특징, 장단점) → **불릿** `-`
- 항목이 굵직하면 **소제목**이나 **구분선(`---`)** 으로 끊어 호흡을 준다.

## 8. 문체

- **기본은 캐주얼한 합쇼체.** 정중하되 딱딱하지 않게, 독자에게 말 거는 톤("~해봅시다", "~하는 겁니다", 필요시 "여러분").
- **비유와 극단 예시**로 추상 개념을 구체화한다("조금 극단적인 예를 들면…").
- 같은 핵심을 **여러 관점에서 반복**해 각인시킨다(심화 글일수록).
- 톤은 글마다 조정 가능하지만, 지정이 없으면 **캐주얼 합쇼체가 기본값**이다. (레퍼런스는 반말이 섞이나 이 블로그는 합쇼체로 통일.)

## 9. 글 말미 — 참고자료

- 마지막에 **`## 📚 참고자료`** 섹션을 두고 출처·공식 문서를 링크한다.
- Claude Code 공식 문서 도메인은 **`code.claude.com/docs/en/...`** (구 `docs.claude.com`은 301 리다이렉트).
- 링크가 죽지 않도록 **URL은 쓰기 전에 실제 존재를 확인**한다.

## 10. 글 유형별 템플릿

### A. 개념 설명글 (예: "JWT란")

```
도입(왜 알아야 하나) → 배경/문제 → 개념 + 다이어그램 → 시나리오/예시(caseN)
→ 한 문장 요약 → 📚 참고자료
```

### B. How-to · 상세 기능글 (예: hook/loop/routine **상세** 글이 여기)

```
도입(무엇을 해결하나) → 언제 쓰나 → 동작 원리 + 다이어그램
→ 설정 단계(번호 리스트 + 코드블록) → 실전 예시 → 함정·주의(💡/⚠️ 콜아웃)
→ 한 문장 요약 + 관련 글 → 📚 참고자료
```

### C. 추천 리스트글 (예: "VSCode 확장 추천")

```
도입(선정 기준·신뢰도) → [ 항목명 → 한두 줄 설명 → 공식 링크 → 이미지/GIF → (선택)팁 ] 반복
→ 항목 간 구분선 → 마무리 → 📚 참고자료
```
- 모든 항목이 **동일 패턴**이어야 스캔이 쉽다.

### D. 심화·원리 탐구글 (예: "스레드는 많을수록 좋은가")

```
도입(흔한 오해 제시) → 표면적 답 → 숨은 변수들(다각도 반복) → 상황별 분석(대조 구조)
→ 극단 예제 + 코드 → 핵심 재강조 → 📚 참고자료
```
- 용어는 `>` 정의 블록으로 고립시켜 혼동을 막는다.
