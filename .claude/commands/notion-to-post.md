노션 페이지 `$ARGUMENTS` 를 블로그 글로 옮긴다. **원문을 그대로 옮기는 것**이 목적이다 — 내용을 요약하거나 다시 쓰지 않는다.

인자가 비어 있으면 노션 링크를 달라고 하고 멈춘다.

## 1. 노션 페이지 가져오기

1. `notion-fetch` 로 페이지를 가져온다(도구가 지연 로드 상태면 ToolSearch `select:mcp__claude_ai_Notion__notion-fetch` 로 먼저 불러온다).
2. 제목, 속성의 `생성일`, 본문을 확인한다. `truncated`·`unknown_block_count` 가 있으면 빠진 블록이 있다는 뜻이니 사용자에게 알린다.

> ⚠️ **이미지 URL은 서명 URL이라 5분 뒤 만료된다**(`X-Amz-Expires=300`). 2단계에서 글을 쓸 위치를 묻기 **전에**, 이미지를 스크래치패드 디렉터리로 먼저 받아 둔다. 만료됐으면(403) `notion-fetch` 를 다시 불러 새 URL로 받는다.

- 본문의 `![](https://prod-files-secure…)` 를 **등장 순서대로** 모두 받는다. 페이지 아이콘(`iconMetadata`)은 받지 않는다.
- URL들은 `X-Amz-Security-Token` 등 쿼리 대부분이 같고 경로의 블록 ID와 `X-Amz-Signature` 만 다르다. 공통 부분을 셸 변수로 두면 긴 URL을 한 번만 쓰면 된다.
- 받은 뒤 `file` 로 전부 실제 이미지인지(HTML 에러 페이지가 아닌지) 확인한다.

## 2. 위치 묻기 (대화형)

`AskUserQuestion` 으로 묻는다. 후보는 실제 폴더에서 뽑는다 — `find src/content/posts -type d -not -name image` 로 카테고리(**`ko.md`가 없는 폴더**)를 나열한다.

1. **카테고리**: 기존 카테고리 폴더 중 내용과 가장 맞는 것을 첫 번째에 `(Recommended)` 로 둔다. 새 카테고리가 필요하면 "Other"로 입력받는다.
2. **글 폴더 이름(slug)**: 노션 제목을 영어 kebab-case로 옮긴 후보 2~3개를 준다. 이 이름이 URL이 된다.
3. **공개 여부**: `draft: false`(바로 공개) / `draft: true`(초안).

같은 카테고리의 기존 글이 있으면 하나를 읽어 frontmatter 형식(제목 앞 커스텀 이모지 `:이름:` 등)과 문체를 맞춘다. 커스텀 이모지는 `src/assets/emoji/` 에 있는 것만 쓴다.

## 3. 이미지 배치

- 받은 이미지를 `<글폴더>/image/` 로 옮기고 **내용을 나타내는 kebab-case 이름**을 붙인다(`image.png` 그대로 두지 않는다).
- **이미지를 Read로 한 장씩 열어 본다.**
  - 글자가 없거나 영어만 있는 이미지 → 언어중립. 접미사 없이 한 장(`boxplot.png`)으로 두고 ko/en이 같이 참조한다.
  - **한국어 글자가 들어 있는 이미지** → 규칙상 `.ko.`/`.en.` 짝이 필요하다. 원본은 `<이름>.ko.<ext>` 로 두고, 영문판을 만들 수 없으면 사용자에게 알리고 어떻게 할지 묻는다(임의로 한국어 이미지를 en에 쓰지 않는다 — 훅이 막는다).

## 4. ko.md 작성 — 원문 그대로

frontmatter:

```yaml
---
title: "<노션 제목 (같은 카테고리 관례대로 이모지 접두사)>"
date: <노션 생성일을 KST로, 예: 2026-10-03T21:32:00+09:00>
description: "<본문 내용을 한 문장으로>"
tags: [<주제 태그들>]
draft: <2단계 답>
---
```

노션 → 마크다운 변환 규칙:

| 노션 | 블로그 |
| --- | --- |
| `<callout icon="📌">…</callout>` | 같은 아이콘의 인용 블록 `> 📌 …`. 내부 줄바꿈·목록은 `>` 접두사 + 문단 사이 `>` 빈 줄 |
| `<span underline="true">**X**</span>` | `<u>**X**</u>` |
| `<table>` (HTML 표) | 마크다운 표. 첫 행을 헤더로 |
| 표 안의 `\[` `\]` `\<` | `[` `]` `&lt;` (이스케이프 해제, `<` 는 엔티티로) |
| `$$ … $$` 수식 | 그대로 |
| 코드 블록 | 언어 표기 포함 그대로 |
| `<empty-block/>` | 버린다 |
| `## 참고자료` | `## 📚 참고자료` (스타일 가이드 관례) |
| 이미지 | `![<그림을 설명하는 한국어 alt>](./image/<이름>.png)` — 노션엔 alt가 없으니 새로 쓴다 |

- 헤딩 단계·번호·문장·강조·목록 구조는 **노션 원문 그대로** 둔다. 블록 사이엔 빈 줄을 넣는다.
- **오타·문법 오류는 고치지 않는다.** 대신 발견한 것을 목록으로 모아 마지막 보고에서 알리고, 고칠지 사용자에게 묻는다.

## 5. en.md 번역

- 같은 폴더에 `en.md` 를 만든다. 블록 순서·개수·표·수식·코드·링크·이미지 경로는 ko와 **똑같이**, 문장만 자연스러운 영어로 옮긴다. 이미지 alt도 영어로 쓴다.
- frontmatter의 `date`·`tags`·`draft` 는 ko와 동일하게 둔다.
- ko에 오타가 있으면 en은 **뜻이 맞는 쪽으로** 옮기고, 4단계 오타 목록에 함께 적는다(ko를 그대로 두면 커밋 때 drift 검사에 걸릴 수 있다는 점도 알린다).

## 6. 검증

```bash
node scripts/drift-blocks.mjs <글폴더>     # 무료 — ko/en 블록 정렬 확인
npm run dev:status                          # 떠 있지 않으면 npm run dev
curl -s http://localhost:4321/posts/<경로> -o <스크래치패드>/p.html -w "%{http_code}\n"
```

받은 HTML에서 `<img`·`<table`·`<blockquote`·`katex` 개수가 ko/en 둘 다 들어간 만큼(원문 개수 × 2) 나오는지 센다.

> 유료 의미 검사(`check-drift`·`npm run drift`)는 돌리지 않는다. 커밋할 때 pre-commit이 한 번 돌린다.

## 7. 보고

- 만든 파일 경로와 이미지 수
- 노션과 달라진 점(콜아웃 → 인용 블록, alt 추가, 이모지 접두사 등)
- 4단계에서 모은 **오타·문법 오류 목록** — 고칠지 묻는다
- **커밋·배포는 하지 않는다.** 사용자가 요청하면 그때 한다.
